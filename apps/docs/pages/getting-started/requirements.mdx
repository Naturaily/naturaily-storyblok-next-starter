# 👌 Requirements to get started

```bash
node - v18.18.2
pnpm - v10.11.0
```

### ✅ Node

To install Node.js, you can follow the nvm documentation available at [https://github.com/nvm-sh/nvm](https://github.com/nvm-sh/nvm).

```bash copy
nvm use 18.18.2
```

Once installed, you can check the version using the following command:

```bash copy
node --version
```

Ensure that the command returns `v18.18.2` to confirm that you have the correct version installed.

### ✅ PNPM

The Turbo Repo utilizes PNPM package manager.

To install PNPM, you can follow the official documentation available at [https://pnpm.io/](https://pnpm.io/). Once installed, you can check the version using the following command:

```bash copy
pnpm --version
```

Ensure that the command returns `10.11.0` to confirm that you have the correct version installed.
