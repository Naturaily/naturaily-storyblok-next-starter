# 👌 Requirements to get started

```bash
node - v22.17.0
pnpm - v10.11.0
```

<Callout type="info">
  There is a known issue with PNPM 10 regarding `eslint` and `prettier`. To make sure your development environment is set up correctly, please add following code to the `pnpm-workspace.yaml`:

```yaml
publicHoistPattern:
  - '*eslint*'
  - '*prettier*'
```

You can read more about those issues:

- [eslint issue](https://github.com/microsoft/vscode-eslint/issues/1986#issuecomment-2799868163)
- [prettier issue](https://github.com/prettier/prettier-vscode/issues/3104#issuecomment-2834447583)

</Callout>

### ✅ Node

To install Node.js, you can follow the nvm documentation available at [https://github.com/nvm-sh/nvm](https://github.com/nvm-sh/nvm).

```bash copy
nvm install 22
```

Once installed, you can check the version using the following command:

```bash copy
node --version
```

Ensure that the command returns `v22.17.0` or higher to confirm that you have the correct version installed.

### ✅ PNPM

The Turbo Repo utilizes PNPM package manager.

To install PNPM, you can follow the official documentation available at [https://pnpm.io/installation](https://pnpm.io/installation). Once installed, you can check the version using the following command:

```bash copy
pnpm --version
```

Ensure that the command returns `10.11.0` to confirm that you have the correct version installed.
