import { Steps, Callout } from 'nextra/components';

<Steps>
### Import repository to Vercel

![Vercel](/vercel-import.webp)

- Ensure that the `root directory` is set to `apps/web` (it should be the default).

- Add environment variables. You will find all the variables after successfully completing the setup process at this path: `apps/web/.env`

### Set the preview domain in Storyblok CMS

If the deployment process was successful, copy the page address and add it to Storyblok.

Copy `URL` from Vercel:
![Vercel success](/vercel-domain.webp)

Paste `URL` in Storyblok:
![Vercel success](/storyblok-preview.webp)

<Callout type="warning" emoji="⚠️">
  `URL` should end with `/api/draft?slug=` **slash**.

_Example:_
`https://<your-domain-name>.vercel.app/api/draft?slug=`

This ensures that the live preview works correctly.

</Callout>

### Setup revalidate webhook

A webhook allows for updating pages without the need to rebuild the entire project.

As the endpoint URL, pass:

`https://<your-domain>/api/revalidate`

You have to create a `STORYBLOK_WEBHOOK_SECRET` in the in the Vercel dashboard and paste value from created `apps/web/.env` file.

![Vercel success](/revalidate.webp)

<Callout type="warning" emoji="⚠️">
  Remember to check all the checkboxes in the `Story` accordion
</Callout>

<Callout type="info" emoji="ℹ️">
  More information about revalidate webhook [here](/packages/storyblok/storyblok-revalidate)
</Callout>

</Steps>
