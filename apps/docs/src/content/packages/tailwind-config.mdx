# tailwind-config

## 💻 Tailwind default config

[Tailwind](https://tailwindcss.com/) is used for quick and optimized styling of components.
This package provides the default Tailwind configuration and necessary dependencies.

If you're using VS Code, install the [official Tailwind CSS IntelliSense plugin](https://marketplace.visualstudio.com/items?itemName=bradlc.vscode-tailwindcss).
It includes a dedicated language mode with support for all custom at-rules and functions used by Tailwind CSS.

<Callout type="info">
If the Tailwind CSS IntelliSense plugin is not working as expected, please add it's config file manually in .vscode/settings.json:

```json
{
  "tailwindCSS.experimental.configFile": "packages/tailwind-config/global.css"
}
```

You can read more about that issue [here](https://github.com/tailwindlabs/tailwindcss-intellisense/issues/1155)

</Callout>

Files included in this package:

- `global.css` - adds Tailwind base styles and contains all custom configurations. Since v4, it replaces the tailwind.config.js file.

- `postcss.config.js` - contains the PostCSS configuration for the project.

## 🤓 Configuration

<Steps>
  ### Add dependency inside apps/web

Import this package in the apps that use TailwindCSS by adding it as a dev dependency to `package.json` file:

```json
"devDependencies": {
  "tailwind-config": "workspace:*",
}
```

### Configure `global.css` file in `tailwind-config`

Import `tailwindcss` and specify the source paths of your packages to make Tailwind work correctly. You can also add plugins with `@plugin` directive. Make sure to add all required variables (e.g. shadcn/ui variables).

```css copy filename="packages/tailwind-config/global.css"
@import 'tailwindcss';

@source "../../apps/web/src/app/**/*.{js,ts,jsx,tsx}";
@source '../storyblok/src/components/**/*.{js,ts,jsx,tsx}';

@plugin "@tailwindcss/typography";

:root {
  --background: hsl(0 0% 100%);
  --foreground: hsl(224 71.4% 4.1%);
  --card: hsl(0 0% 100%);
}

/* * When defining theme variables that reference other variables, use the inline option: */
@theme inline {
  --color-background: var(--background);
  --color-foreground: var(--foreground);
  --color-card: var(--card);
}
```

### `postcss.config.mjs` file

Create a `postcss.config.mjs` file in each app and packages that uses TailwindCSS, and paste the following code:

```js copy filename="packages/[your-package]/postcss.config.mjs"
export { default } from 'tailwind-config/postcss.config.mjs';
```

### Import the shared `global.css` file into your application's layout

```tsx copy
import 'tailwind-config/global.css';
```

### Usage

Use [tailwind classes](https://tailwindcss.com/docs/aspect-ratio) in your components within the package/app you implemented the config to:

```tsx /w-full my-5 p-5 md:my-10/
<div className="my-5 w-full p-5 md:my-10" />
```

</Steps>

## 🤓 Extending the default settings

As mentioned above, all custom styles should be added inside the `global.css` file. Learn more about customizing Tailwind styles [here](https://tailwindcss.com/docs/adding-custom-styles)
