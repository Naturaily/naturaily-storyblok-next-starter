# Storyblok preview

A package handling [preview mode](https://www.storyblok.com/tp/create-a-preview-environment-for-your-next-js-website) in Storyblok.

## Components

### DraftModeProvider

Component that serves 2 purposes:

- rendering the `<DraftModeContext.Provider />`,
- rendering the button we can click to leave the draft mode, if it's turned on:

![Button we can click to leave the draft mode](/draft-mode-button.webp)

Usage example:

```tsx filename="Providers.tsx" {5,13}
'use client';

import { ReactNode } from 'react';

import { DraftModeProvider } from '@natu/storyblok/DraftModeProvider';

interface ProvidersProps {
  children?: ReactNode;
  draftMode?: boolean;
}

export const Providers = ({ children, draftMode }: ProvidersProps) => (
  <DraftModeProvider draftMode={draftMode}>{children}</DraftModeProvider>
);
```

API Reference:

| Prop      |    Type     | Default | Description                                 |
| :-------- | :---------: | ------: | ------------------------------------------- |
| children  | `ReactNode` |       - | Children of the `DraftModeProvider`         |
| draftMode |  `boolean`  | `false` | Flag that tells if we are in the draft mode |

#### DraftModeContext

The `DraftModeContext` defined in the `DraftModeProvider` is available since the `DraftModeProvider` is used in the `Providers` component. Usage in server components:

```tsx
import { draftMode } from 'next/headers';

const Page = async () => {
  const { isEnabled } = await draftMode();

  return <div>Hello world!</div>;
};
```

## Draft Mode

### Route Handler

The draft mode is implemented as a route handler located at `apps/web/src/app/api/draft/route.ts`.

This route handler:

- Validates the Storyblok preview token
- Enables draft mode using Next.js `draftMode().enable()`
- Redirects to the appropriate page with draft mode enabled

<Steps>
  ### Setup the Route Handler

Create a route handler at `/api/draft/route.ts`:

```tsx filename="/app/api/draft/route.ts"
import { draftMode } from 'next/headers';
import { redirect } from 'next/navigation';
import { NextRequest, NextResponse } from 'next/server';
import { env } from '@natu/env';

// Token validation function
const validateStoryblokPreviewToken = async ({
  previewToken,
  queryParams,
}: {
  previewToken: string;
  queryParams: URLSearchParams;
}) => {
  const spaceId = queryParams.get('_storyblok_tk[space_id]');
  const timestamp = queryParams.get('_storyblok_tk[timestamp]');
  const token = queryParams.get('_storyblok_tk[token]');

  if (!spaceId || !timestamp || !token) {
    return false;
  }

  const validationString = [spaceId, previewToken, timestamp].join(':');

  const data = new TextEncoder().encode(validationString);
  const sha1Hash = await crypto.subtle.digest('SHA-1', data);
  const hashArray = Array.from(new Uint8Array(sha1Hash));
  const hashHex = hashArray.map(b => b.toString(16).padStart(2, '0')).join('');

  return hashHex === token;
};

export const GET = async (request: NextRequest) => {
  const { searchParams } = new URL(request.url);
  const slug = searchParams.get('slug');

  // Validate the token
  const isValid = await validateStoryblokPreviewToken({
    queryParams: searchParams,
    previewToken: env.NEXT_PUBLIC_STORYBLOK_PREVIEW_TOKEN,
  });

  if (!isValid) {
    return NextResponse.json({ error: 'Unauthorized' }, { status: 401 });
  }

  const draft = await draftMode();
  const redirectSlug = !slug ? '/' : `/${slug}`;

  // Enable draft mode and redirect
  draft.enable();
  redirect(`${redirectSlug}?${searchParams.toString()}`);
};
```

### Configure Storyblok Visual Editor

In your Storyblok space settings, configure the preview URL to point to your draft route:

```
https://your-website.com/api/draft?slug=
```

### Using Draft Mode in Server Components

In server components, use the `draftMode` function from Next.js to check if draft mode is enabled:

```tsx filename="app/[...slug]/page.tsx"
import { draftMode } from 'next/headers';
import { getStoryblokSdk } from '@natu/storyblok/api';

export default async function Page({ params }: { params: { slug: string[] } }) {
  const { isEnabled } = await draftMode();
  const { getContentNode } = getStoryblokSdk({ draftMode: isEnabled });

  const awaitedParams = await params;

  const slug = getSlugWithAppName({ slug: getSlugFromParams(awaitedParams.slug) });

  if (isSlugExcludedFromRouting(slug)) {
    notFound();
  }

  const { data } = await tryCatch(getContentNode({ slug }));

  if (!data || !data?.data?.story?.content) {
    notFound();
  }

  return <StoryblokStory story={data?.data?.story} />;
}
```

## Utils

### handleDisableDraft

A client-side helper function that disables the draft mode by making a request to a specific endpoint. This function is already used in the `DraftModeProvider` component to implement the "Exit Draft Mode" button.

```tsx
'use server';

import { draftMode } from 'next/headers';

export const handleDisableDraftAction = async () => {
  (await draftMode()).disable();
};
```

### isDraftMode

A utility function that checks if draft mode is enabled based on the provided value and environmental variables. It returns a boolean indicating whether draft mode is active. This function is particularly useful for configuring the Storyblok API client.

```tsx
import { env } from '@natu/env';

export const isDraftMode = (draftMode: boolean) =>
  draftMode ||
  process.env.NODE_ENV !== 'production' ||
  env.NEXT_PUBLIC_STORYBLOK_TOKEN_VERSION === 'draft';
```
